# docs/datasheets/

Reference datasheets for the TWI hardware and common slave devices used by the
demo and tests.

## Suggested additions

- **NXP UM10204** — the I2C-bus specification. Download from
  <https://www.nxp.com/docs/en/user-guide/UM10204.pdf> and drop it in this
  folder.
- **Microchip 24LC256** — 256 kbit serial EEPROM used by `examples/demo.c`.
  <https://ww1.microchip.com/downloads/en/DeviceDoc/21203M.pdf>.
- **ATmega328P** TWI chapter — section 22 of the ATmega328P datasheet.
- **ATmega32** TWI chapter — section 21 of the ATmega32 datasheet.

Files in this folder are not tracked unless you commit them explicitly.
